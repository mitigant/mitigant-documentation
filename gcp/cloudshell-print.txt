To complete Mitigant GCP Attack Emulation setup:

Have your GCP Project ID ready -- the script will ask for it.

1. Run the setup script:

   bash setup.sh

   When prompted, enter your GCP Project ID (the same one you
   entered in the Mitigant onboarding screen).

2. Copy the JSON key printed between the separator lines at the end.

3. Return to the Mitigant onboarding screen and paste the JSON
   into the Service Account Key field, then click Connect.
